# 图书管理系统

基于 Rust + Tauri + React 的本地图书管理桌面客户端，用于维护馆藏、读者及借还记录。所有业务数据保存在本机，日常操作可离线完成。

6 个首版功能已实现并集成到主分支。框架先行提交，各模块通过独立 worktree 和多个 agent 并行完成；自动检查与 macOS 原生流程验证见[交付验证](verification.md)。用户业务验收待进行。

## 基本功能与范围

| 编号 | 功能 | 范围 | 状态 |
|---|---|---|---|
| F01 | 图书管理 | 录入、编辑、检索、查看馆藏及停用单本实体书 | 已实现 |
| F02 | 读者管理 | 建立读者档案、查询、编辑及停用 | 已实现 |
| F03 | 借书登记 | 选择读者与实体书，校验后登记借出 | 已实现 |
| F04 | 还书登记 | 查询当前借阅，登记归还并恢复可借状态 | 已实现 |
| F05 | 借阅查询 | 查询在借、逾期、已归还记录与历史借阅 | 已实现 |
| F06 | 数据备份与恢复 | 手动导出完整备份、校验并恢复本地数据 | 已实现 |

首版服务单机小型图书室，由一名管理员操作，不设登录和角色权限。暂不包含云同步、多人协作、预约、续借、罚款、在线 ISBN 信息补全、封面上传、批量导入、扫码设备集成或独立统计看板。

## 实施顺序

1. 初始化桌面应用和数据库，完成图书管理、读者管理。
2. 完成借书、还书及借阅查询，验证完整借还闭环。
3. 完成备份恢复，验证重启持久化及桌面交互，再进行人工验收。

框架提交为 `1d81203`；4 个模块分支及 worktree 保留，分支提交已集成到主分支。路径与后续使用方式见 [README](../README.md#并行开发)。

## 首版业务选择

| 项目 | 首版基线 | 影响 |
|---|---|---|
| 使用场景 | 单机小型图书室，一名管理员操作 | 若用于个人藏书或多机协作，需要调整读者、借阅或部署范围 |
| 借阅政策 | 默认借期 30 个自然日，每位读者最多同时借 5 本；首版固定规则，不提供设置页 | 直接影响借出校验与到期日；具体定义见[借阅公共规则](modules/circulation.md#核心业务规则) |

用户在现有设计基础上授权开发，本次采用上述建议作为首版基线。技术检查与原生流程验证已记录，用户业务验收单独进行。
