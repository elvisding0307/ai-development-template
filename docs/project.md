# 图书管理系统

基于 Rust + Tauri + React 的本地图书管理桌面客户端，用于维护馆藏、读者及借还记录。所有业务数据保存在本机，日常操作可离线完成。

当前正在搭建项目框架，以下业务能力尚未实现。用户已授权按现有设计开发，先提交框架，再通过独立 worktree 与多个 agent 并行实施。

## 基本功能与范围

| 编号 | 功能 | 范围 | 状态 |
|---|---|---|---|
| F01 | 图书管理 | 录入、编辑、检索、查看馆藏及停用单本实体书 | 规划中 |
| F02 | 读者管理 | 建立读者档案、查询、编辑及停用 | 规划中 |
| F03 | 借书登记 | 选择读者与实体书，校验后登记借出 | 规划中 |
| F04 | 还书登记 | 查询当前借阅，登记归还并恢复可借状态 | 规划中 |
| F05 | 借阅查询 | 查询在借、逾期、已归还记录与历史借阅 | 规划中 |
| F06 | 数据备份与恢复 | 手动导出完整备份、校验并恢复本地数据 | 规划中 |

首版建议服务单机小型图书室，由一名管理员操作，不设登录和角色权限。暂不包含云同步、多人协作、预约、续借、罚款、在线 ISBN 信息补全、封面上传、批量导入、扫码设备集成或独立统计看板。

## 建议开发顺序

1. 初始化桌面应用和数据库，完成图书管理、读者管理。
2. 完成借书、还书及借阅查询，验证完整借还闭环。
3. 完成备份恢复，验证重启持久化及桌面交互，再进行人工验收。

本次按上述顺序实施；模块在框架提交后进入独立 worktree 并行开发。

## 首版业务选择

| 问题 | 建议 | 影响 |
|---|---|---|
| 使用场景 | 单机小型图书室，一名管理员操作 | 若用于个人藏书或多机协作，需要调整读者、借阅或部署范围 |
| 借阅政策 | 默认借期 30 个自然日，每位读者最多同时借 5 本；首版固定规则，不提供设置页 | 直接影响借出校验与到期日；具体定义见[借阅公共规则](modules/circulation.md#核心业务规则) |

用户在现有设计基础上授权开发，本次采用上述建议作为首版基线。业务验收仍需在实现后单独记录。
