# 图书管理

- 所属模块：[馆藏](../../modules/catalog.md)
- 状态：已实现
- 技术验证：本模块变更已通过 `npm run build`、`npm test`（含 6 条馆藏交互测试）、`cargo test --manifest-path src-tauri/Cargo.toml modules::catalog`（6 条 SQLite 集成测试）、Rust 格式及 Clippy 严格检查。
- 业务验收：待人工验收；单模块自动检查不代表原生桌面和跨模块流程已验收，使用场景见[首版选择](../../project.md#首版业务选择)。

## 用途与目标

维护可单独借还的实体书，支持录入、编辑、列表检索、详情及停用／重新启用，作为借还操作的馆藏基础。

## 输入与输出

| 项目 | 内容 | 约束 |
|---|---|---|
| 输入 | 馆藏编号、书名、作者、ISBN、出版社、分类、位置 | 编号必填，1～32 位英文字母、数字、短横线或下划线，统一转大写；书名必填，最多 200 字符；作者及出版社最多 100，ISBN 最多 32，分类及位置最多 50；其余可空 |
| 输入 | 搜索词、状态、页码；目标图书 ID 与编辑／停用操作 | 搜索词最多 200 字符；状态为全部、可借、借出、停用 |
| 输出 | 馆藏列表、详情、保存结果或字段错误 | 每页 20 条，按创建时间倒序、内部 ID 稳定排序；显示编号、书名、作者、分类、位置和状态 |

ISBN 为可选人工记录字段，首版不核验其真实存在，不通过 ISBN 自动获取书目信息。字符串处理及 IPC 错误遵守[全局规范](../../architecture.md#全局代码规范)。

## 行为

1. 进入页面展示全部图书和总条数，提供搜索、状态筛选及“新增图书”。搜索对馆藏编号、书名、作者、ISBN 作字面子串匹配；英文字母忽略大小写，不把通配符当作查询语法。
2. 在侧栏填写资料并保存；成功后显示新记录。编号唯一性及状态遵守[馆藏公共规则](../../modules/catalog.md#核心业务规则)。
3. 编辑侧栏允许修改编号以外的资料；取消保留原数据。有未保存内容时关闭侧栏须确认丢弃。
4. 详情显示当前资料、当前借阅概要及“查看借阅记录”入口。已借出图书可编辑资料，既有借阅快照保持原值。
5. 停用前二次确认，通过后更新状态；允许重新启用。借出时禁止停用并提示先归还。可借图书提供“办理借出”跳转并预选实体书。
6. 修改筛选条件时回到第一页；保存后刷新列表与详情。若因当前筛选导致新记录不可见，仍提示保存成功并提供查看详情入口。

## 边界与异常

| 情况 | 预期处理 | 可观察结果 |
|---|---|---|
| 编号重复，含大小写差异 | 按规范化编号拒绝保存 | 标注编号冲突，保留输入 |
| 必填为空或字段超长 | 拒绝保存 | 定位对应字段，无新记录 |
| 空馆藏／无搜索结果 | 展示不同空状态 | 空馆藏可直接新增，无搜索结果可清除条件 |
| 停用同时发生借出 | 在事务边界重新检查 | 仅一种操作成功，不能留下停用且在借的图书 |
| 数据库写入失败 | 回滚并返回存储错误 | 原记录保持，允许修正后重试 |

## 验收标准

| 编号 | 给定条件 | 操作或事件 | 预期结果 |
|---|---|---|---|
| AC-01 | 空库 | 录入 B001 与书名并保存 | 出现一条可借图书；关闭重启后仍存在 |
| AC-02 | 已有 B001 | 使用 b001 再次录入 | 报编号冲突，总记录数不变 |
| AC-03 | 两本同 ISBN、不同馆藏编号的书 | 分别录入 | 均保存成功，可分别借还 |
| AC-04 | 已有一条图书记录 | 修改书名、搜索新书名 | 可找到更新记录，编号不变 |
| AC-05 | 图书处于借出状态 | 尝试停用 | 失败并提示先归还；借阅保持有效 |
| AC-06 | 图书可借 | 停用再重新启用 | 依次显示停用、可借；详情和历史均保留 |
| AC-07 | 已录入超过 20 本且状态混合 | 搜索、筛选并翻页 | 结果、条数与页码一致，切换条件回到第一页 |

实体及关联关系见[共享数据关系](../../architecture.md#共享数据关系)。
