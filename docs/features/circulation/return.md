# 还书登记

- 所属模块：[借阅](../../modules/circulation.md)
- 状态：已实现
- 技术验证：本模块已通过 `npm run build`、`npm test`（4 条借阅界面模拟 IPC 测试，另含 2 条框架测试）、`cargo test --manifest-path src-tauri/Cargo.toml`（9 条借阅测试，另含 2 条框架测试）及严格 Clippy 检查。覆盖事务回滚、并发唯一性／名额、日期边界、历史快照、归还幂等及组合查询。当前为模块 worktree 验证，尚待主分支集成与原生桌面验证。
- 业务验收：待人工验收。

## 用途与目标

根据实体书或读者找到当前未归还记录，确认归还并立即释放可借资格，保留完整借阅历史。

## 输入与输出

| 项目 | 内容 | 约束 |
|---|---|---|
| 输入 | 馆藏编号，或读者编号／姓名及搜索结果中的借阅 ID | 只对未归还记录办理；选择时显示读者和实体书编号消除歧义 |
| 输出 | 归还时间、图书状态、读者在借数量与办理结果 | 归还时间由后端生成；重复提交返回原已归还结果 |

## 行为

1. 在还书页签按馆藏编号查找，或选择读者列出其未还记录；借阅查询页也可预选一条记录进入。
2. 展示借出时的读者与图书信息、借出时间、应还日期、当前逾期情况，管理员确认归还。
3. 按[借阅公共规则](../../modules/circulation.md#核心业务规则)在事务中记录归还时间；不删除借阅，不补录其他归还日期。
4. 成功后刷新当前借阅、图书状态及读者在借数量，显示归还结果。停用读者的归还正常办理。
5. 同一借阅再次提交返回“已归还”及原归还时间；即使该图书已形成新的借阅，也不能归还新借阅。

## 边界与异常

| 情况 | 预期处理 | 可观察结果 |
|---|---|---|
| 实体书没有未还记录 | 不办理归还 | 提示未找到当前借阅 |
| 查询多个候选 | 要求选择具体记录 | 不默认操作第一条 |
| 借阅已经归还 | 返回原结果 | 原归还时间不变，不重复减少在借数量 |
| 借阅 ID 不存在 | 拒绝办理 | 显示不存在，无数据变化 |
| 系统时间早于借出时间 | 拒绝归还并提示校准系统时钟 | 保持未归还，不保存时间逆序记录 |
| 存储失败或维护中 | 拒绝或回滚 | 保持未归还状态，允许重试 |

## 验收标准

| 编号 | 给定条件 | 操作或事件 | 预期结果 |
|---|---|---|---|
| AC-01 | 一条未归还借阅 | 按馆藏编号确认归还 | 保存归还时间，图书恢复可借，在借数量减少 1，历史保留 |
| AC-02 | 读者已停用且有未还记录 | 办理归还 | 正常完成，读者仍停用 |
| AC-03 | 已归还记录 | 重复提交同一借阅 ID | 提示已归还，归还时间和数量不变 |
| AC-04 | 图书归还后已被再次借出 | 提交旧借阅 ID 的归还请求 | 新借阅仍未归还，不影响当前借阅人 |
| AC-05 | 逾期借阅 | 办理归还 | 转为已归还，保留应还日期，可查逾期归还，无罚款 |
| AC-06 | 归还事务提交失败 | 查询该借阅及图书 | 仍未归还、仍借出，在借数量不变 |
