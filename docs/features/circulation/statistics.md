- 业务验收：用户已确认“没问题，提交”，本次借阅统计功能验收通过。

## 用途与目标

新增独立“借阅统计”导航，以现有馆藏和借阅记录展示当前概况、最近 7 天借还趋势、累计热门图书及馆藏分类分布。只读统计，不新增数据表，不修改借阅政策或历史记录。

## 输入与输出

| 项目 | 内容 | 约束 |
|---|---|---|
| 输入 | 打开统计页、点击刷新、业务数据变化、窗口重新聚焦或跨日 | 日期由 Rust 读取系统本地日期；首版固定最近 7 天，不接受前端自定义日期或统计值 |
| 输出 | 当前图书数、读者数、在借数、逾期未还数，7 天借出／归还次数，热门前 5 本及全部分类数量 | 各区域来自同一次数据库读取事务；显示统计日期和实际更新时间 |

## 行为与统计口径

1. 统计页沿用现有深绿与暖白界面，展示四张概况卡、借还趋势图与同值明细表、热门馆藏列表、分类数量条形图。颜色仅作辅助，图表同时提供文字及数值。
2. 总图书数和读者数包含停用档案；当前在借包含逾期未还；逾期遵守[借阅公共规则](../../modules/circulation.md#核心业务规则)，不含已归还记录，到期当天不算逾期。
3. 最近 7 天包含今天和此前 6 个自然日，按日期升序补齐无记录的日期为 0。借出按借出时间转换为当前系统本地日期计次；归还按已保存的归还本地日期计次，与历史归还分类口径一致。区间外记录不计入趋势；同一图书多次借还分别计次。
4. 热门馆藏按每本实体书的累计借出次数降序排列，次数相同时按馆藏编号、内部 ID 升序稳定排序，只展示借出次数大于 0 的前 5 本；启用与停用馆藏均计入。显示当前书名及馆藏编号，同名副本独立统计；点击可按图书 ID 查看其借阅历史。
5. 分类分布按现有实体书的当前分类汇总，包含停用馆藏；空分类归入“未分类”，与显式填写“未分类”的图书合并。按数量降序、分类名升序排列，所有分类数量之和等于总图书数。
6. 借出、归还、馆藏或读者维护成功后重新查询；恢复备份后沿用应用级页面状态重置。窗口重新聚焦、跨午夜及手动刷新也会重新计算。普通页面切换保持可用结果。
7. 空库显示概况为 0、7 天零值趋势，以及热门馆藏和分类的空状态，不构造示例统计。全部请求失败时提供重试；刷新失败可保留上次结果，但必须标为旧数据，不显示为最新成功结果。刷新期间禁用重复刷新按钮。

## 边界与异常

| 情况 | 处理 | 可观察结果 |
|---|---|---|
| 无近 7 天借还，但有历史记录 | 趋势补零，热门统计仍包含累计借阅 | 不把累计次数当作近 7 天次数 |
| 应还日期等于今天 | 不计入当前逾期 | 次日重算后才计入 |
| 数据包含损坏的借阅日期 | 整次统计返回结构化存储错误 | 不静默略过记录或显示不完整统计 |
| 正在备份或恢复 | 遵守 Store 维护互斥 | 显示维护中原因，可稍后重试 |
| 已打开页面跨日 | 重新读取后端日期及统计 | 趋势窗口向前移动一天，逾期数重新计算 |

## 验收标准

| 编号 | 给定条件 | 操作或事件 | 预期结果 |
|---|---|---|---|
| AC-01 | 空库 | 打开统计 | 四项为 0，趋势恰好 7 天且全为 0，热门与分类为空状态 |
| AC-02 | 近 7 天起止边界与区间外均有借还 | 查询统计 | 边界当天计入，区间外排除，缺失日期补零，归还按保存的本地日期计次 |
| AC-03 | 未到期、到期当天、逾期未还及逾期已还记录并存 | 查询概况 | 在借包含全部未归还，逾期只含应还日期早于今天的未还记录 |
| AC-04 | 多本同名副本、不同累计次数及并列次数 | 查询热门 | 仅前 5 本，累计次数正确，顺序稳定；档案改名后显示当前书名，历史快照不变 |
| AC-05 | 多分类、空分类、停用图书 | 查询分布 | 分类总数等于全部馆藏数，未分类正确合并，停用图书计入 |
| AC-06 | 已有统计结果 | 借还或维护成功、聚焦、手动刷新或跨日 | 页面重新读取，数值与数据库一致；未修改业务记录 |
| AC-07 | 请求失败或刷新失败 | 重试 | 提供错误说明；旧结果明确标记，恢复后显示成功数据 |
| AC-08 | 热门列表有记录 | 点击查看借阅记录 | 通过稳定图书 ID 导航，不以书名过滤同名副本 |
