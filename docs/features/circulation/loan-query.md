# 借阅查询

- 所属模块：[借阅](../../modules/circulation.md)
- 状态：规划中
- 技术验证：尚无实现，未执行应用测试。
- 业务验收：待实现后人工验收；逾期口径依赖待确认借期。

## 用途与目标

查询当前借阅与借还历史，识别逾期未还图书，并从记录进入归还操作。

## 输入与输出

| 项目 | 内容 | 约束 |
|---|---|---|
| 输入 | 关键词、状态、借出日期区间、可选读者／图书 ID、页码 | 关键词最多 200 字符；状态为全部、在借、逾期、已归还；日期区间可单边，双边时起始不晚于结束 |
| 输出 | 借阅列表、筛选后总数、借阅详情 | 每页 20 条，按借出时间倒序、内部 ID 稳定排序；展示借出时姓名／书名／编号、借出时间、应还日、归还时间及状态 |

## 行为

1. 默认查看全部记录。关键词对借出时的读者编号、姓名、馆藏编号、书名快照作字面子串搜索，英文忽略大小写；界面明确标注搜索历史快照信息。
2. 图书或读者详情跳转通过内部 ID 过滤其全部关联记录，覆盖档案改名之前的历史；显示当前对象筛选标签，清除后恢复全局查询。
3. 筛选条件同时生效；“在借”包含逾期未还，“逾期”只包含逾期未还，“已归还”包含按期和逾期归还。分类口径遵守[借阅公共规则](../../modules/circulation.md#核心业务规则)。
4. 借出日期区间按当前系统本地日期解释，含起止当日；查询由后端执行，分页总数使用相同筛选条件。更改筛选条件回到第一页。
5. 当前逾期显示逾期天数；已归还记录按公共规则比较已保存的归还本地日期和应还日，显示“逾期归还”及天数，之后不受设备时区变化影响。
6. 未归还记录提供“办理归还”，已归还记录只读。日期变更或页面重新聚焦时重新查询，归还成功后刷新结果。

## 边界与异常

| 情况 | 预期处理 | 可观察结果 |
|---|---|---|
| 无记录或无匹配 | 展示空状态并允许清除条件 | 不误显示加载中或错误 |
| 日期区间无效 | 拒绝查询 | 标出日期问题，保留条件 |
| 到期当天或跨午夜 | 后端按本地日历日期分类 | 到期当日不逾期，次日刷新为逾期 1 天 |
| 档案信息已经修改 | 历史显示快照，ID 关联保持 | 不将新书名／姓名伪装为借出时信息 |
| 查询失败 | 显示错误和重试入口 | 已显示结果明确标记为旧结果，不冒充最新数据 |

## 验收标准

| 编号 | 给定条件 | 操作或事件 | 预期结果 |
|---|---|---|---|
| AC-01 | 在借、逾期未还、已还各有记录 | 依次切换状态 | 在借含逾期，逾期排除已还，已归还含全部归还记录 |
| AC-02 | 应还日期 2026-11-30 且未归还 | 分别于 11 月 30 日和 12 月 1 日刷新 | 前者不逾期，后者逾期 1 天 |
| AC-03 | 应还日后 2 天归还 | 查看已归还记录 | 显示逾期归还 2 天，不出现在当前逾期列表 |
| AC-04 | 借出后读者及图书改名 | 从档案查看历史并用旧名称搜索 | ID 跳转仍能找到记录，旧名称匹配快照，列表标明借出时信息 |
| AC-05 | 记录超过 20 条 | 组合关键词、日期和状态筛选并翻页 | 结果和总条数匹配，无重复或遗漏；修改条件回到第一页 |
| AC-06 | 当前逾期记录在详情完成归还 | 返回原逾期筛选 | 记录从当前逾期列表消失，在已归还中可查 |
| AC-07 | 页面在到期当日保持打开 | 跨午夜或重新聚焦 | 触发后端重算并展示次日逾期状态 |
