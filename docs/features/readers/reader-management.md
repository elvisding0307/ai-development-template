## 用途与目标

建立借阅人的稳定身份，支持新增、编辑、查询、查看借阅概要、停用和重新启用。

## 输入与输出

| 项目 | 内容 | 约束 |
|---|---|---|
| 输入 | 读者编号、姓名、联系电话、备注 | 编号必填，1～32 位英文字母、数字、短横线或下划线，统一转大写；姓名必填且最多 100 字符；电话最多 32、备注最多 500，可空 |
| 输入 | 搜索词、启用状态、页码；目标读者 ID 和操作 | 搜索词最多 100 字符；状态为全部、启用、停用 |
| 输出 | 读者列表、详情、保存或停用结果 | 每页 20 条，按创建时间倒序、内部 ID 稳定排序；显示编号、姓名、电话、在借数量和启用状态 |

电话作为联系文本记录，允许空格、国家区号等，不强制中国大陆手机号格式。公共身份和停用规则见[读者模块](../../modules/readers.md#核心业务规则)。

## 行为

1. 列表支持读者编号、姓名、电话的字面子串搜索与启用状态筛选；英文搜索忽略大小写，改变条件回到第一页。
2. 新增表单提交经后端校验后创建启用读者；同名或相同联系方式可保存，界面始终同时展示编号用于区分。
3. 编辑姓名、电话或备注，不允许修改编号；未保存内容关闭时确认丢弃。保存失败保留输入，保存成功刷新详情和列表。
4. 详情展示在借数量并链接至该读者的借阅查询；启用读者可跳转借书工作台并预选本人。
5. 停用时显示姓名、编号和在借数量，经确认停用；允许重新启用。对停用读者不提供新增借书操作，既有借阅仍可办理归还。刷新筛选结果后若当前页超过有效末页，自动回到有效末页并重新读取。

## 边界与异常

| 情况 | 预期处理 | 可观察结果 |
|---|---|---|
| 规范化编号重复 | 拒绝保存 | 显示编号冲突，已有档案不变 |
| 姓名空白、字段超长 | 拒绝保存 | 显示字段错误，不写入 |
| 有未还图书 | 停用确认中提示在借数量 | 停用后历史可查、仍可归还 |
| 目标记录不存在 | 提示数据不存在并刷新 | 不创建替代记录 |
| 写入失败 | 回滚 | 原档案不变，保留编辑内容 |

## 验收标准

| 编号 | 给定条件 | 操作或事件 | 预期结果 |
|---|---|---|---|
| AC-01 | 空读者库 | 仅填编号 R001、姓名后保存 | 新建启用读者，电话和备注可空，重启后仍存在 |
| AC-02 | 已有 R001 | 新增 r001 | 报编号冲突，原档案不变 |
| AC-03 | 已有同名读者 | 使用不同编号创建同名读者 | 创建成功，列表可按编号区分 |
| AC-04 | 读者有未归还借阅 | 停用并确认 | 显示停用，禁止新增借书，仍可归还原借阅 |
| AC-05 | 停用读者 | 重新启用 | 恢复可借资格，在借数量按原记录计算 |
| AC-06 | 读者已有借阅历史 | 修改姓名并打开历史 | 当前档案显示新姓名，历史仍显示借出时姓名 |
| AC-07 | 列表有多页记录 | 组合搜索与状态筛选、打开借阅入口 | 列表条件有效，借阅页仅展示该读者 ID 对应记录 |
| AC-08 | 启用读者 21 条，当前为第 2 页唯一一条 | 停用该读者并确认 | 自动回到第 1 页，显示剩余 20 条启用读者，不停留在空的第 2 页 |
