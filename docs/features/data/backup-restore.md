# 数据备份与恢复

- 所属模块：[数据管理](../../modules/data.md)
- 状态：已实现
- 技术验证：本分支前端生产构建、3 条恢复确认／取消交互测试、Rust 数据模块 11 条测试入口（含进程中断子进程）及 Clippy 严格检查通过。覆盖完整备份恢复、安全备份找回、源文件变更、非法备份、维护互斥、失败保留数据及进程退出后的数据库重开。原生文件对话框与跨模块验证见[交付验证](../../verification.md)。
- 业务验收：待用户人工验收，重点确认覆盖恢复提示及备份可用性。

## 用途与目标

管理员将全部本地数据保存为一个可恢复文件，并在确认后用合法备份完整替换当前数据，避免手动处理应用数据库。

## 输入与输出

| 项目 | 内容 | 约束 |
|---|---|---|
| 输入 | 备份保存位置，或待恢复的备份文件及确认操作 | 使用原生文件对话框；按[数据管理公共规则](../../modules/data.md#核心业务规则)校验 |
| 输出 | 备份路径、完成结果；恢复校验摘要、当前数据安全备份路径及恢复结果 | 只有实际完成并通过检查后显示成功；取消无数据修改 |

## 行为

1. 数据管理页显示当前数据目录、数据模式版本及操作说明；提供“创建备份”和“从备份恢复”。
2. 创建备份时提示文件包含读者资料，选择位置，建议文件名包含本地日期时间，扩展名为 .library-backup.sqlite。目标已存在时须确认覆盖。
3. 进入维护状态并等待业务事务完成，使用一致性快照生成备份；完成校验后发布最终文件，显示路径。失败不留下被误认为成功的文件，也不破坏原有目标备份。
4. 恢复时选择文件，校验应用标识、模式版本、SQLite 完整性、外键及业务约束。具体包括必需实体和字段、正数且在 JavaScript 安全整数范围内的内部 ID、唯一编号、单册唯一未归还关系、有效状态值、借阅时间先后关系、历史快照及日期完整性；不把当前借阅上限作为历史库有效性限制。
5. 合法文件展示馆藏、读者、全部借阅及未还数量，标明“恢复会替换全部当前数据，备份之后的修改将丢失”。管理员确认前不修改当前数据。
6. 确认后进入独占维护状态；重新验证来源未被更换，生成当前数据的独立安全备份，再执行恢复。来源在校验后发生变化时要求重新校验和确认。
7. 恢复完成检查通过后，退出维护状态，清空前端缓存、刷新所有数据，显示恢复结果与安全备份路径。发生失败执行回滚；恢复的崩溃一致性遵守[数据管理公共规则](../../modules/data.md#核心业务规则)。

## 边界与异常

| 情况 | 预期处理 | 可观察结果 |
|---|---|---|
| 取消文件选择或覆盖／恢复确认 | 正常取消 | 当前业务数据及既有备份不变 |
| 空库 | 允许完整备份及恢复 | 可恢复为零业务记录，仍保留合法模式 |
| 非本应用、损坏、关系不合法或版本不兼容 | 校验失败，禁止恢复 | 显示具体类别，当前数据不变 |
| 目标为当前数据库或辅助文件，来源为当前活动库 | 拒绝操作 | 提示选择独立文件，不覆盖活动数据库 |
| 磁盘空间不足或无权限 | 停止，必要时回滚 | 当前有效数据和已有备份不损坏 |
| 安全备份失败 | 不开始替换 | 显示失败原因，当前数据保持可用 |
| 备份恢复中再次触发操作 | 拒绝并提示维护中 | 不并发执行，不接收新的借还或编辑写入 |
| 恢复中断或应用崩溃 | 下次启动先完成恢复检查或回滚 | 只打开完整有效数据库；无法安全恢复时停止业务写入并提示错误 |

## 验收标准

| 编号 | 给定条件 | 操作或事件 | 预期结果 |
|---|---|---|---|
| AC-01 | 有馆藏、读者、在借及已还记录 | 创建备份 | 生成合法文件并显示路径，当前数据不变 |
| AC-02 | 已备份后又新增记录 | 恢复旧备份并确认 | 数据恢复到备份时点，新增记录消失；替换前状态另有安全备份 |
| AC-03 | 已恢复旧备份 | 再恢复自动生成的安全备份 | 能找回替换前完整数据，包含此前新增记录 |
| AC-04 | 当前已有数据 | 取消任意文件选择或恢复确认 | 当前数据、原备份均无变化 |
| AC-05 | 损坏、错误应用、外键不合法、重复未还或版本不同的文件 | 分别尝试恢复 | 全部拒绝，说明原因，当前数据保持 |
| AC-06 | 无保存权限或模拟磁盘写入失败 | 备份或恢复 | 不误报成功，旧备份和当前有效数据保留 |
| AC-07 | 借还请求执行中 | 开始备份恢复并再次提交业务请求 | 等待旧事务结束，新请求得到维护中反馈，无混合快照 |
| AC-08 | 恢复写入过程被中断 | 重启应用 | 数据为完整旧版本或完整恢复版本，借阅关系有效，无半恢复库可写 |
| AC-09 | 完成恢复 | 查看各页面并关闭重启 | 列表无旧缓存、数据计数和借阅状态与恢复结果一致 |
